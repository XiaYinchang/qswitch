# 账号管理与多环境 Web

qswitch 按“实例 → 工具 → 已核实身份的账号 → 额度窗口 / 会话状态”组织管理。每台机器对自己的客户端和账号负责；Deck 提供统一入口，目标页面仍由各实例独立运行和鉴权。

## 能力与边界

| 类型 | 登录与身份 | 查询与续期 | 切换范围与限制 |
|---|---|---|---|
| Codex | 隔离 Device Code；账号 / workspace 身份 | 官方额度、闲置 OAuth 续期 | CLI 凭据；未核实身份的桌面快照不恢复；桌面运行时不能声称生成空闲 |
| Grok CLI | 隔离 Device Code；指定账号槽必须命中 | 当前共享账期，预付费 / 按量余额保留；官方 OAuth 锁 | CLI 凭据；不改 Grok Bot；多槽身份不明确时拒绝 |
| Cursor | 官方客户端登录后收录；核对 IDE / CLI 一致性 | Auto / API 额度与额外余额；当前未实现安全续期 | 同时写 IDE 和 CLI；桌面状态不可验证时要求先退出 |
| Grok Bot | Cursor 账号关联的只读额度 | 独立观测时间与失败状态 | 不提供独立切号，不把浏览器快照绑定到 Grok CLI |
| Devin CLI | 在线验证 API key 所属身份 | 按套餐识别日 / 周窗口，Max 只看周额度 | CLI 配置；Devin App 独立，不随 CLI 关闭或换号 |
| Kimi Code | 官方登录后 `/me` 核验 | 官方额度；同身份桌面月额度只读补充；macOS/Linux 一次性 OAuth 续期可恢复，Windows 由原生客户端续期 | 所有 Kimi CLI 退出后更新凭据；不自动发送续接 |
| Claude Code | Linux 隔离授权；官方 profile 核验 | 5h / 7d；一次性续期日志与恢复 | Linux/macOS 文件凭据；macOS Keychain 不支持；受管会话空闲协调，保留现有提前轮换政策；Windows 不支持受管切换 |
| ZCode | 读取桌面 Coding Plan | 5h / 周模型额度，月 MCP 单独展示 | 只读监控，不替客户端登录或切号 |
| Antigravity | 原生 App / agy 登录；系统凭据及原生身份核验 | Gemini、第三方各 5h / 周，支持 macOS / Linux / Windows | 两组均确认耗尽才自动切；原生会话空闲后统一更新 App / CLI，核验失败回滚 |

各平台的动作由后端 capability 决定，不靠前端按工具名称猜测。没有可靠接口的能力明确显示原因；不会为了表面一致而启用无法验证的桌面操作。新增账号登录由使用者完成。

## 状态和额度

认证有效性、额度、会话忙闲、自动切换设置和实例范围分别展示。未安装、未登录、未知、接口失败、历史观测和明确耗尽不能互相替代。关闭自动切换只停止切号，继续收录、查询和安全续期；全局关闭时，单工具开关不会冒充已经生效。

耗尽使用供应商原始字段和真实上限，不把 99.5% 当成 100%。缺失必要窗口时保持未知；协议明确规定的省略零值仍按该协议处理。Grok Bot 查询失败不能继承 Cursor 查询成功的时间。

Antigravity 按以下条件执行：

1. 每组任一完整有效窗口达到上限，该组受限。
2. Gemini 和第三方两组均受限，且结果完整、成功、未过期，才允许排队。
3. 缺失窗口、接口失败、重置时间不明确或任一组恢复时，撤销旧证据及待切任务。
4. 候选账号按最长窗口的重置时间先后选择；不使用 Claude 提前轮换规则。

Claude 保留原有最长窗口 12 小时内、余量至少 10%、早于当前账号重置的提前轮换，以及受管会话后台等待上限和 cron 规则。普通非受管 Claude 不纳入切号协调。

## 可靠性

工具锁覆盖收录、续期、查询与切换。配置更新在跨进程锁内重读，只改指定字段。凭据写入失败或最后的状态提交失败时回滚受影响文件；缺失文件恢复为缺失，Cursor 只回滚认证键，不覆盖其他数据库内容。

Kimi 和 Claude 在消费一次性 refresh token 前先持久记录意图；新凭据先加密落盘，再写账号与当前登录。重启后可以恢复未完成写回；外部新登录和主动登出不覆盖。响应丢失时停止重用旧 token，重新登录可以替代不确定的凭据。对不透明 token，内容不同不代表账号不同；必须核对当前在线身份再消费闲置凭据。

这些保证覆盖已有操作的明确失败和 OAuth 续期中断；不承诺任何供应商、任意客户端版本上的完整事务或未公开接口稳定性。

## Web 操作

桌面按工具、账号列表、账号详情组织，手机按屏宽折叠。常用动作集中在所属工具和账号，自动开关放在工具管理区。删除放入次级操作；额度四个窗口、错误原因、观测时间及恢复状态可直接查看。

“刷新页面”只读本机状态，“查询额度”才请求供应商。后台只读刷新在页面可见时运行，不反复重建整个页面；保留焦点、选择和展开状态。同工具写操作互斥，旧响应不能覆盖新结果。写请求超时显示结果待核验，不自动重放；供应商查询失败不会被后续刷新掩盖。

Device Code 登录提供复制、有效期、重试、取消和焦点恢复；轮询串行，取消后不继续更新旧会话。页面、登录页和对话框使用同一套视觉、键盘和无障碍语义。

## 实例、权限与发布

实例 ID 自动持久生成，显示名可配置，版本和 worker 范围来自当前 daemon。导航地址携带预期 ID；登录和写操作核对实际 ID。环境目录只存导航元数据，不包含凭据。每个远程实例独立网页登录，关闭页面不改变供应商登录。

所有 Web API 写请求要求实例标识，浏览器还要求同源。Book 仅管理 Antigravity 时，总览和操作也只有该工具，不显示其他工具已托管的假象。账号凭据不跨机复制；同账号多机观测不汇总为重复额度。

发布用一个标签和清单覆盖 novix、Mini、Book。构建在 devbox / CI，安装前校验制品、切号状态和当前版本，安装后核对实例 ID、版本、范围、总览与公开入口。失败回滚，成功删除临时文件与备份；登录供应商不作为安装完成条件。

平台能力由合成回归、原生 CI 和可达设备分别验证；真实账号登录与真实耗尽切号须与代码实现、部署和合成验收分开记录。
